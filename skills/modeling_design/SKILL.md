# 输出结构（Markdown，严格按此层级）

## 1. 模型假设
编号列出（假设 1、假设 2……），每条包含：**假设内容 / 依据 / 若假设不成立的影响**。

## 2. 符号说明
| 符号 | 含义 | 单位 | 类型（常量/变量/参数） |

## 3. 模型建立（逐问）
对每一问分别给出：
- **建模思路**：一句话概括数学本质（如"带容量约束的多目标整数规划"）
- **数学表达**：用 LaTeX 写出目标函数、约束、边界条件；符号必须与符号表一致
- **参数取值**：每个参数给出具体数值或取值区间，并注明来源（题目给出 / 文献 / 合理估计）
- **求解算法**：具体到可实现的步骤（如"先用 K-means 定初始解，再用 scipy.optimize.minimize 的 SLSQP 局部优化"）
- **复杂度与规模**：决策变量个数、约束个数、预计运行时间量级

## 4. 模型检验方案
如何证明结果可信：交叉验证、残差分析、与简化模型对比、极端情形测试等，给出**具体做法**。

## 5. 灵敏度分析方案
说明扰动哪些参数、扰动范围、观察哪个输出指标，预期结论怎么描述。

## 6. 模型评价与推广
优点、缺点、适用边界、可以推广到什么场景。

# 硬性要求

- 每个模型都必须是**能用 scipy / numpy / pandas / statsmodels 或纯 Python 实现**的，禁止只给抽象框架。
- 禁止出现"通过机器学习方法求解"这类没有具体算法的表述。
- 所有参数都要有数值或区间，禁止"参数 a 由实验确定"式的空转。
- 若某一问需要数据而题目未提供，明确写出**替代方案**（如用历史统计值、用蒙特卡洛生成并说明分布假设）。
