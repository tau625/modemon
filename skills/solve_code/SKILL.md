# 输出格式（必须严格遵守）

每个文件用**独立代码块**给出，代码块第一行必须是文件路径注释：

```python
# file: solve/main.py
import numpy as np
...
```

规则：
1. 每个代码块 = 一个文件；路径用 `# file: <相对路径>` 标注。
2. 至少包含 `solve/main.py` 作为入口，顺序执行即可复现全部结果。
3. **必须**在最后用标准输出打印一行 JSON 汇总，格式固定：
   `RESULT_JSON {"问题1": {"最优值": 123.45, ...}, "问题2": {...}}`
   所有论文要用到的数字都必须出现在这一行里。
4. 中间结果写盘：`results/*.json` 或 `results/*.csv`。
5. 代码必须健壮：随机算法要固定 `np.random.seed(42)`；求解器不收敛时要给出降级方案而不是崩溃。
6. 中文注释，变量名用英文；禁止 `plt.show()`（图表由后续环节单独生成）。
